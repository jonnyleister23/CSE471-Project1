System overview

How it works

01 / Subtractive instrument

Notes start as harmonic-rich sawtooth, square, or triangle waves built from band-limited tables. Each note gets its own pitch, amplitude envelope, and resonant low-pass filter with an independent filter envelope.

Read instrument details

02 / Effects and mixing

Individual notes can send different amounts of audio to chorus, flanging, reverb, and ring modulation. The dry and processed channels are combined into the final stereo output.

Read effects details
Sequencer

XML score format

The Synthie sequencer reads a .score file containing XML. The score defines tempo and timing through bpm, beatspermeasure, measure, and beat. Each note specifies its pitch, duration, waveform, volume and filter settings. It can also set dry and wet sends for each effect. Both the instrument and effects decisions are stored in the score, rather than chosen manually during playback.

<score bpm="120" beatspermeasure="4">
  <instrument instrument="SubtractiveInstrument">
    <note measure="1" beat="1" duration="1.85"
          note="C3" wave="saw" amplitude="0.065"
          attack="0.025" release="0.16"
          cutoffMin="170" cutoffMax="1800"
          resonance="1.5" filterAttack="0.10"
          filterDecay="0.5" filterSustain="0.30"
          pan="-0.45" dry="0.76" chorus="0.08"
          flange="0.12" reverb="0.21" ring="0.04" />
  </instrument>
</score>

Example simplified from the main score. Envelope time parameters are measured in seconds, while duration is measured in beats.

The program uses the course Step 5 Synthie architecture. Its sequencer starts individual instrument voices at the times specified in the XML. For each output frame, the active voices generate samples, the mixer adds them into dry and effect-send channels, and the effects process those channels. The application writes the result as WAV audio without keeping the entire composition in memory.

Project authorship and assistance

This project was built using my Step 5 starter as the framework. AI assistance was used to help create this website and made sure the audio was 44,100 samples per second, 16 bit stereo. The project was built and WAV outputs were generated in Visual Studio.
