Subtractive
synthesizer.

The instrument begins with a harmonically rich wave and shapes the resulting sound using a resonant low-pass filter. Each note is generated individually.

Waveform generation

The synthesizer supports sawtooth, square, and triangle waveforms. Rather than calculating an ideal discontinuous waveform on every audio frame, it builds a 2,048-sample table for the requested note when the voice starts. The table is created by adding harmonics, keeping the highest harmonic below the Nyquist frequency to reduce aliasing.

Sawtooth

Contains even and odd harmonics. Harmonic strength decreases approximately as 1 / n, with alternating sign.

Square

Contains only odd harmonics, with strengths proportional to 1 / n.

Triangle

Contains only odd harmonics. Strength decreases as 1 / n², with alternating sign.

Pitch comes from the note name in the XML. Playback advances through the table according to note frequency and sample rate, using linear interpolation between adjacent samples.

Amplitude and filter envelopes

Amplitude envelope

An ADSR-style envelope controls how each note starts, decays, sustains, and releases. Attack and decay times, sustain level, and release duration can be changed per note. The release fade also avoids abrupt clicks at note endings.

Filter envelope

A separate envelope sets the filter cutoff between cutoffMin and cutoffMax. As the cutoff moves, more or fewer high frequencies pass through, creating the sweeping sound associated with subtractive synthesis.

Resonance and polyphony

The filter uses a recursive, two-pole resonant low-pass calculation. It keeps previous input and output samples as state and recalculates its coefficients each frame from the cutoff and resonance settings. This gives the filter a stronger response around the cutoff frequency.

For polyphony, the sequencer creates a separate CSubtractiveInstrument object for every note. Several voices can overlap, each with its own table position, filter state, and envelopes. Their current frames are mixed before effects processing.
